# TODO

Known gaps and deferred work. Roughly ordered by impact.

## Features not yet implemented

- [ ] **Redis cache is a stub.** `RedisUrlRepo.GetLongUrl` / `PutShortUrl` return `"", nil`.
      `UrlShortenerService.cacheUrlRepo` is never read, so `ShortenUrl`'s doc comment
      ("persists it into both database and cache") is currently false.
      When implementing: translate `redis.Nil` into `*ShortUrlNotFound` — returning
      `"", nil` means "found, and the answer is the empty string".
- [ ] **Short URL expiration.** `CleanOldUrls` is generated by sqlc but never called.
      Needs a scheduler, and `GetLongUrl` should filter on `created_at` so a row that
      is expired but not yet swept doesn't still resolve.
- [ ] **Click rate tracking** (README capability 4). The 302 redirect is in place,
      which is the prerequisite, but nothing counts hits yet.

## Correctness / robustness

- [ ] **`dev.yaml` and `prod.yaml` are empty.** Viper reads them without error and
      unmarshals a zero-valued `AppConfig` — port 0 and all four HTTP timeouts at 0,
      which silently disables the timeout protection.
- [ ] **No config validation.** Add a check after `viper.Unmarshal`: non-zero port,
      non-empty hosts, non-zero timeouts. Fail at startup, not at first request.
- [ ] **Retry loop has no attempt cap** (`service.go`, `ShortenUrl`). Termination
      currently depends entirely on the 500ms context deadline. Prefer an explicit
      bound (~5 attempts) that returns an error when exhausted.
- [ ] **URL normalization for dedup.** Safe set only (RFC 3986 §6.2.2): lowercase
      scheme, lowercase host, drop default port (:80/:443), empty path -> "/".
      Do NOT touch path case, trailing slashes on non-empty paths, query order,
      `www.`, or tracking params — those change which resource is fetched.
